# Todos Browser Extension

A lightweight companion extension for the Todos web app — designed for fast, distraction-free task management directly from your browser.
Add tasks instantly, view what’s pending, and stay organized without switching tabs.

### ✅ Features
- Quick-add panel for creating tasks in seconds
- View and manage your Todos on any page
- Seamless sync with your main Todos app
- Minimal, modern UI built with React + ShadCN
- Always available from your browser toolbar

This extension is built to enhance your workflow, reduce friction, and help you capture tasks the moment they come to mind — wherever you are on the web.
